# Capture — agent notes

## What this is

Single-purpose macOS overlay launcher. Press a global hotkey, a Spotlight-style glass bar opens, type a thought, hit Enter, the text is fired at a configurable URI (default: Octarine's `octarine://daily?...` to append a line to today's daily desk).

The point is **speed**: hotkey → glass bar → Enter → gone. Don't add features that slow that down. No history, no recents, no fuzzy search, no plugins, no main window, no Dock icon. Lives entirely as a menu-bar app.

The bar persists when focus is lost (only Esc / Enter / the hotkey itself hide it). Multi-line capture grows the bar downward up to 5 lines, then scrolls internally.

## Project layout

```
project.yml                 XcodeGen spec — single source of truth for the Xcode project
Sources/
  CaptureApp.swift          @main App + MenuBarExtra + Settings scene
  AppDelegate.swift         @MainActor, .accessory policy, hotkey registration, panel lifecycle, fade animations
  LauncherPanel.swift       NSPanel subclass (non-activating, transparent, rounded contentView mask)
  LauncherView.swift        SwiftUI input view: .glassEffect, multi-line growth via height preference key
  DailyCapture.swift        URI template substitution ({content}/{time}/{date}), NSWorkspace.open
  HotkeyName.swift          KeyboardShortcuts.Name.toggleLauncher
  SettingsView.swift        URI template editor backed by @AppStorage("uriTemplate")
  Info.plist                LSUIElement=true, bundle metadata (uses $(EXECUTABLE_NAME) etc.)
scripts/
  dev.sh                    fswatch + xcodegen + xcodebuild Debug + relaunch loop
  release.sh                xcodegen + xcodebuild Release + ditto zip for GitHub Releases
```

The `.xcodeproj` is generated by XcodeGen and gitignored. Regenerate after editing `project.yml` or adding/removing source files:

```bash
xcodegen generate
```

`scripts/dev.sh` does this automatically on every Save.

## Build / verify

- Full build: `xcodegen generate && xcodebuild -project Capture.xcodeproj -scheme Capture -configuration Debug build`, or open in Xcode and ⌘R.
- No tests. Behavior is verified by running the app: press the hotkey, type, check today's daily file appended.

## Hard constraints

- **macOS 26 Tahoe only.** Uses native `.glassEffect()` (Liquid Glass). Don't add fallbacks for older OS versions — this is a personal tool, not a published product.
- **AppKit `NSPanel`** (not SwiftUI `Window`). Required because the overlay must be `.nonactivatingPanel` — SwiftUI `Window` scenes can't express non-activating behavior and always steal focus from the frontmost app.
- **Hard-won non-activating panel settings** (`Sources/LauncherPanel.swift`):
  - `hidesOnDeactivate = false`. With `.accessory` + `.nonactivatingPanel`, the system fires app-deactivated almost immediately on subsequent shows; with `true`, the panel auto-hides on every show after the first.
  - `canBecomeKey = true`, `canBecomeMain = false`.
  - `backgroundColor = .clear`, `isOpaque = false`, `animationBehavior = .none` (we animate the fade ourselves so show and hide match).
  - `container.layer.cornerRadius = 28` + `masksToBounds = true` — clips the contentView's rectangular corners to match the glass capsule's rounded shape so `windowBackgroundColor` doesn't leak through.
  - `invalidateShadow()` after every resize so the drop shadow re-traces the new content silhouette.
- **No "panel resigned key" as a dismiss signal.** Non-activating panels routinely lose key status for OS-internal reasons; using `didResignKeyNotification` to dismiss caused the panel to vanish ~1 second after showing. The bar now only dismisses on Esc / Enter / hotkey toggle.
- **`NSWorkspace.shared.open(url, configuration:)` with `config.activates = false`.** Required so opening the URI doesn't bring Octarine (or whichever target app) to the foreground.
- **One runtime dependency.** [`KeyboardShortcuts`](https://github.com/sindresorhus/KeyboardShortcuts) for the global hotkey (wraps Carbon `RegisterEventHotKey`). Declared in `project.yml`'s `packages:` block.

## Hotkey

Default is `⌃⌘Space`. Defined in `Sources/HotkeyName.swift`. The library persists user-set bindings in `UserDefaults` automatically; changing the `default:` only affects fresh installs. No Recorder UI is exposed in Settings yet — if rebinding becomes a need, add `KeyboardShortcuts.Recorder` to `SettingsView.swift`.

## URI template

The default ([`Sources/DailyCapture.swift`](Sources/DailyCapture.swift)) is the existing Octarine quicklink. Editable via Settings. Three placeholders, all URL-encoded on substitution:

- `{content}` — captured text
- `{time}` — `HH:mm`
- `{date}` — `yyyy-MM-dd`

Stored in `UserDefaults` under key `"uriTemplate"`. The default template is restored if the stored value is empty / whitespace-only.

## Multi-line growth

Implemented as a SwiftUI `PreferenceKey` (`HeightKey` in `LauncherView.swift`) reading from a `GeometryReader` in the view background. The value is propagated up via `onHeightChange` → `AppDelegate` → `LauncherPanel.resize(toHeight:)`. The panel preserves its top edge and grows downward by recomputing `origin.y = oldMaxY - newHeight` in a single `setFrame` call. `lineLimit(1...5)` caps growth at 5 lines; beyond that the field scrolls internally.

## Fade animations

`animationBehavior = .none` on the panel, and `AppDelegate.showPanel` / `hidePanel` use `NSAnimationContext` with a fixed `0.1s` duration on `alphaValue` for both directions. After fade-out, `orderOut(nil)` is called and `alphaValue` is reset to `1` for the next show.

## Distribution

Personal use, ad-hoc signed. `scripts/release.sh <version>` produces a zipped `.app` ready for a GitHub Release. Gatekeeper will prompt on first open from `/Applications`; right-click → Open, or `xattr -dr com.apple.quarantine /Applications/Capture.app`.
